# Rock-Paper-Scissors Game 🎮

A simple game built to demonstrate JavaScript logic, event handling, and responsive UI design.

### 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3
* **Logic:** JavaScript 

### ✨ Key Features
* **Real-time Scoring:** Tracks player and computer wins
* **Responsive Design:** Fully functional on mobile and desktop

Developed by a Computer Science Student at ITM University, Gwalior.
